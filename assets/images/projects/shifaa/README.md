# Shifaa screenshots

Add real Shifaa Clinic Management System screenshots in this folder.

Recommended files:

- `shifaa-dashboard.webp` — 1600 × 1000 px main image
- `shifaa-mobile-patient.webp` — 900 × 1600 px
- `shifaa-mobile-doctor.webp` — 900 × 1600 px
- `shifaa-admin.webp` — 1600 × 1000 px

Search for `SHIFAA IMAGE` in the root `index.html` to replace the current SVG path.
