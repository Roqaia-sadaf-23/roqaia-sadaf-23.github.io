# E-commerce screenshots

Add real E-commerce project screenshots in this folder.

Recommended files:

- `ecommerce-cover.webp` — 1200 × 800 px main image
- `ecommerce-01.webp`, `ecommerce-02.webp`, etc. — use a consistent aspect ratio

Search for `E-COMMERCE IMAGE` in the root `index.html` to replace the current SVG path.
