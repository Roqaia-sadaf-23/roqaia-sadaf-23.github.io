# Ozzo screenshots

Add real Ozzo mobile project screenshots in this folder.

Recommended files:

- `ozzo-cover.webp` — 1200 × 800 px main image
- `ozzo-01.webp`, `ozzo-02.webp`, etc. — use a consistent aspect ratio

Search for `OZZO IMAGE` in the root `index.html` to replace the current SVG path.
